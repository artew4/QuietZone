# ТИХАЯ ЗОНА

Атмосферный браузерный 3D‑прототип об исследовании советского микрорайона в тёплый осенний вечер. Игрок начинает у гаража № 17, может пройтись по двору, осмотреть жилые дома, детскую площадку и техническую территорию, открыть ворота и зайти в уютную лабораторию физика.

## Запуск

Требуется Node.js 20 или новее.

```bash
cd app
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Для production‑сборки:

```bash
npm run build
npm run preview
```

## Управление

- **WASD / стрелки** — движение.
- **Мышь** — осмотр от первого лица.
- **Shift** — быстрый шаг.
- **Space** — начать исследование / прыжок.
- **E** — взаимодействие с воротами и приборами.
- **Esc** — пауза и освобождение курсора.

В лаборатории работают переключатели осциллографа, радиоприёмника и настольной лампы. Настройка звука сохраняется локально в браузере; прогресс и аккаунты не используются.

## Что реализовано

- Компактный район с двумя жилыми домами, научным корпусом и гаражным кооперативом.
- Детализированные фасады: оконные рамы, балконы, подъезды, козырьки, водостоки, антенны и вывески.
- Детская площадка, лавочки, фонари, теплотрасса, бельевые верёвки, велосипед, покрышки, бочки и другой реквизит.
- Гараж‑лаборатория с рабочим столом, осциллографом, радио, паяльной станцией, книгами, инструментами, диваном, ковром, обогревателем и чайником.
- Анимированная синусоида, открывающиеся двустворчатые ворота, качающиеся качели, движение крон и падающие листья.
- FPS‑контроллер с плавным ускорением, покачиванием камеры, прыжком и пространственной сеткой коллизий.
- Тёплое солнечное освещение, мягкие тени, туман, светящиеся окна и локальное освещение лаборатории.
- Процедурный ветер, шаги, птицы, электрический гул и радиопомехи через Web Audio API.
- Стартовый экран, минимальный HUD, пауза, итог прогулки и рестарт.

Выживание, инвентарь, крафт, строительство, NPC и боевые механики намеренно не входят в эту версию.

## Проверка

```bash
cd app
npm run build
npm run verify
npm run verify:full
```

Базовая проверка тестирует рендер, запуск, направления WASD, паузу и консоль. Расширенная дополнительно проверяет все направления движения, столкновения со зданием и закрытыми воротами, открытие гаража, проход внутрь, переключатели приборов, кнопки, звук, рестарт и изменение размера окна. Скриншоты проверки создаются во временной папке `verification-shots/`.

Для проверки в установленном Chrome с аппаратным ускорением на macOS:

```bash
CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" HEADED=1 npm run verify:full
```

Финальный прогон выполнен в Chrome на Apple M5 / ANGLE Metal при 1920×1080: 114 FPS, 195 draw calls и 139 864 треугольника. Фактический FPS зависит от устройства и сцены; программный SwiftShader используется только для функциональных тестов, а не для оценки производительности.

## Структура

```text
app/
├── src/
│   ├── game/
│   │   ├── Game.ts                 # состояния, цикл и координация систем
│   │   ├── player/                 # FPS‑контроллер
│   │   ├── systems/                # физика, свет, звук, взаимодействия, эффекты
│   │   ├── world/                  # район и архитектура мира
│   │   │   └── prefabs/            # дома, гаражи, лаборатория, природа, реквизит
│   │   └── utils/                  # геометрия, материалы, текстуры, PRNG
│   └── pages/Home.tsx              # canvas и DOM‑интерфейс
├── scripts/verify-game.mjs          # базовый браузерный smoke‑тест
└── scripts/verify-full.mjs          # полный интерактивный тест
```

## Технологии и ресурсы

Three.js, TypeScript, Vite, React и Lucide. Все модели, материалы, CanvasTexture и звуки создаются процедурно внутри проекта. Внешние изображения, модели, аудиофайлы, CDN и серверная часть не используются.

Исходное творческое задание сохранено в `PROJECT ТИХАЯ ЗОНА.txt`.
